About this page

Interactive components (dropdowns, collapse, modal, offcanvas, carousel, toasts, tooltips, popovers, scrollspy, navbar and tabs) and ready-made page blocks for Northwind Studio. Static classes are on the Classes page, forms on the Forms page.

Dropdowns

Menu items are buttons here, so picking one never changes the URL. Links (a.dropdown-item) work the same way.

Single button: dropdown-toggle + dropdown-menu

Split button: dropdown-toggle-split

Directions: dropup, dropup-center, dropdown-center, dropend, dropstart

Menu content: header, active, disabled, divider, item text; dropdown-menu-end
